# Ruinart × Anish Kapoor — visite 3D

Projet étudiant : une visite guidée de la Maison Ruinart à Reims, de la cour d’honneur jusqu’au fond des crayères, à la rencontre d’Anish Kapoor.

Projet étudiant de direction artistique, 2026. Cette collaboration est imaginée et n’engage ni la Maison Ruinart ni Anish Kapoor.

## Ouvrir le site

Ouvrir `index.html` dans un navigateur récent (Chrome, Edge, Firefox, Safari) : la visite fonctionne hors ligne, sans installation. Le dossier `oeuvres/` doit rester à côté de `index.html`.

## Contenu

- `index.html` : le site (visite 3D au défilement)
- `textes.js` : tous les textes et les réglages de typographie, modifiables avec un éditeur de texte
- `oeuvres/` : les modèles 3D (œuvres, bouteille Ruinart, kakémono), chargés par `oeuvres/oeuvres.js`
- `visuels/` : les visuels du print
- `polices/` : polices facultatives
- `LISEZ-MOI.txt` : mode d’emploi détaillé
